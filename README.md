# 经营分析工作台（dsh-finops-workbench）

把一份 Excel / CSV 经营明细，变成一套**可直接交付**的经营分析：数据体检 → 口径确认 → 趋势 / 结构 / 异常分析 → 可编辑的 xlsx 与一页结论 docx。

数据只在本机读取和计算，不上传任何服务器；导出物保存在本机工作台目录，随取随用。

## 能做什么

1. **数据接入**：选择文件夹或直接粘贴路径，读取 `.xlsx` / `.xlsm` / `.csv`（自动识别 UTF-8 / GB18030 编码与分隔符，自动定位表头行）。
2. **数据体检**：逐列识别类型（数值 / 日期 / 文本）、缺失率与示例值，列出需要处理的数据问题；自动跳过「合计 / 总计 / 小计」行。
3. **口径映射**：用下拉框确认「日期、收入、成本、费用、维度」分别对应哪一列，口径不清时先用建议值再微调。
4. **分析结果**：营业收入、毛利、毛利率、期间费用、净利润、净利率、月均收入；月度趋势与收入环比；按维度（渠道 / 门店 / 产品）的收入结构与毛利率；异常与提示（缺金额、重复行、负收入、极端值、环比波动、亏损月、负毛利维度、收入集中度）。
5. **交付文件**：一次生成两份可编辑文件——
   - `*.xlsx`：概览、趋势、结构、异常、数据体检、口径卡、原始明细，全部使用**原生 Excel 公式**（打开即重算）；
   - `*.docx`：一页结论，含摘要、关键指标、趋势观察、收入结构、异常与建议、口径说明。
6. **复跑对比**：同一份数据再次生成时，自动与上一次结果对比（营业收入、毛利率、净利润变化）。

## 数据要求

- 一行一条经营流水，至少包含：**收入列**（必填）；建议包含日期列（用于月度趋势）。
- 成本、费用、维度列可选：没有成本列时毛利等于收入，没有费用列时净利等于毛利，没有维度列时跳过收入结构。
- 金额请用数值；带「元 / 万元」等单位的文本会按数值近似读取，正式使用前建议在源表统一单位。

## 计算口径

- 毛利 = 收入 − 成本
- 净利润 = 毛利 − 期间费用
- 毛利率 = 毛利 ÷ 收入；净利率 = 净利润 ÷ 收入；费用率 = 期间费用 ÷ 收入
- 收入环比 = 本月收入 ÷ 上月收入 − 1

## 本机目录

默认根目录 `工作台根目录/finops-workbench`（由 bundle 配置 `dshHomePath('finops-workbench')` 指定）：

- `exports/`：生成的 xlsx / docx 与 `history.json`（复跑对比用）
- `samples/`：示例经营数据

## 技术结构

- `index.js`：Host 侧入口，注册 `/api/finops-workbench/*` 本机接口（info / list / inspect / analyze / report / sample / reveal / download）。
- `engine/finops.py`：分析引擎，使用 DSH Desktop 自带的 office-runtime Python（openpyxl + python-docx + pandas）生成 xlsx / docx。
- `client.js`：Client 侧单文件面板，整页业务布局（customFrame），左侧步骤栏 + 主工作区，按需打开 AI 对话。
- `cordis.patch.yml`：bundle 注册与根目录配置。

## 已知限制（v0.1）

- 单文件分析；一次只读一个工作表（默认第一个有数据的表）。
- 不做多表关联与多文件合并。
- 金额单位沿用源表，不做自动换算。
- 个人财务场景请等 v0.2 的独立模板（流水分类、资产负债、储蓄率），不要直接套用经营口径。
